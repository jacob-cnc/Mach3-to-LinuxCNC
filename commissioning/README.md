# Commissioning checklist

- [ ] Backup actual Mach3 profile and VFD settings.
- [ ] Record motor, drive, VFD, supply and controller model numbers.
- [ ] Trace physical wiring with power isolated; document voltage and polarity.
- [ ] Verify independent E-stop and safe spindle/drive inhibit.
- [ ] Select motion controller and map I/O.
- [ ] Verify axis scale, direction, travel and switch behavior at reduced speed.
- [ ] Verify homing, soft limits, probe, spindle speed and cooling.
- [ ] Test fault response and loss of communications.
- [ ] Measure backlash, repeatability and accuracy; record results.
